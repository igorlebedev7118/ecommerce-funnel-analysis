# E-commerce Funnel Analysis

**Tools:** Google BigQuery, SQL, Tableau, GA4

## Project Overview

This project explores e-commerce user behaviour, acquisition channels and purchase conversion using Google Analytics 4 data.

## Key Metrics

- Total sessions: 354,857
- Purchases: 4,745
- Purchase conversion rate: 1.34%

## Analysis

- Conversion funnel performance
- Traffic sources and acquisition channels
- Geographic distribution of sessions
- Purchase trends by operating system
- Weekly conversion performance
